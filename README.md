# Analyse des Ventes PME

Ce projet permet d'analyser les données de ventes d'une PME à l'aide de SQL et de Python.

## 📂 Contenu du projet
- `ventes.csv` : Données brutes des ventes.
- `requetes.sql` : Requêtes SQL pour l'analyse métier.
- `analyse.py` : Script Python pour le traitement des données et la génération de graphiques interactifs (Plotly).
- `ca_par_produit.html` / `ca_par_region.html` : Tableaux de bord interactifs.

## 🚀 Comment l'exécuter ?
1. Installer les dépendances : `pip install pandas plotly`
2. Lancer le script d'analyse : `python analyse.py`
